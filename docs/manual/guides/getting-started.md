# Getting Started

Quick start guide for the Dr. Bubal Care platform.

## Platform Overview

Dr. Bubal Care is an AI-assisted diagnostic coordination platform. It connects patients with board-certified specialists by automating the coordination layer — not the clinical judgment. Every case closes with a human-signed written opinion.

**Core Principle:** *"AI surfaces; specialists decide."*

## Portals

| Portal | URL | Audience |
|--------|-----|----------|
| Patient Portal | `patient.drbubalcare.com` | Patients seeking specialist opinions |
| Specialist Portal | `doctor.drbubalcare.com` | Board-certified medical specialists |
| Admin Portal | `admin.drbubalcare.com` | Platform administrators |

## Quick Start by Role

### Patient Quick Start

1. **Register** — Visit `patient.drbubalcare.com` and create an account (name, email, country, password). Under 2 minutes.
2. **Start a case** — Click "Start a Case", select a service type (specialist opinion, result interpretation, consultation), and describe your situation.
3. **Upload records** — Attach relevant files: lab reports, DICOM scans, medical images, or clinical notes.
4. **Pay** — See exact price before confirming. Pay by card (USD) or local payment method.
5. **Wait** — AI pre-screens your case, then a board-certified specialist reviews it. Target: 24-48 hours.
6. **Receive report** — View your specialist's written opinion with a plain-language summary in your portal.
7. **Follow-up** — Ask questions about your report via the AI assistant, or book a live consultation.

### Specialist Quick Start

1. **Register** — Visit `doctor.drbubalcare.com` and create an account with your credentials and medical registration number.
2. **Verify** — Upload credential documents. Verification typically within 24-48 hours.
3. **Set availability** — Specify your subspecialties, available hours, and case capacity.
4. **Review cases** — Cases arrive with AI pre-screening attached. Review materials and the pre-screen summary.
5. **Write opinion** — Use the structured opinion editor: findings, clinical impression, recommended next steps.
6. **Sign and submit** — Review, sign, and submit. Your signature closes the case.

### Admin Quick Start

1. **Login** — Access `admin.drbubalcare.com` with admin credentials.
2. **Monitor dashboard** — View case routing accuracy, specialist response times, and system health.
3. **Verify specialists** — Review and approve specialist credential submissions.
4. **Handle disputes** — Review patient disputes and assign peer reviews when needed.
5. **Review audit logs** — Monitor all data access for compliance.

## Key Features

| Feature | Description |
|---------|-------------|
| **AI Case Routing** | Automatically matches cases to the right specialist by subspecialty |
| **AI Pre-screening** | Summarizes clinical records before the specialist reviews them |
| **Plain-language Summaries** | Translates specialist opinions into patient-friendly language |
| **Multi-opinion Synthesis** | Combines multiple specialist opinions into a consensus summary |
| **Follow-up Q&A** | Answers patient questions within the scope of the written opinion |
| **Trend Analysis** | Tracks longitudinal lab results and flags significant changes |

## Platform Terminology

| Term | Definition |
|------|-----------|
| **Case** | A patient's diagnostic review request, containing records, opinions, and status |
| **Opinion** | A specialist's written clinical assessment of a case |
| **Pre-screening** | AI-generated summary of key clinical findings before specialist review |
| **Service Type** | The category of review requested (specialist opinion, result interpretation, consultation, trend analysis) |
| **Plain-language Summary** | Patient-friendly translation of a specialist's technical opinion |
| **Synthesis** | AI-generated consensus when multiple specialists review the same case |
| **Follow-up Q&A** | Patient questions answered by AI within the scope of the written opinion |
